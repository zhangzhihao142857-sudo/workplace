# 自动连点器

一款智能鼠标自动连点工具，支持左右键独立控制、CPS 阈值触发、随机扰动等功能。

## 功能特性

- **智能 CPS 检测**：实时监测鼠标点击频率（CPS），达到阈值自动触发连点
- **左右键独立控制**：左键和右键可分别设置触发阈值和连点参数
- **CPS 加成**：在玩家点击基础上自动增加额外 CPS，实现更快点击
- **随机扰动**：支持随机化点击间隔，模拟真实点击行为
- **CPS>-1 模式**：特殊模式，通过绑定按键手动触发连点
- **配置持久化**：所有设置自动保存到配置文件，重启后自动加载
- **透明悬浮窗口**：实时显示 CPS 数据和连点状态，支持拖动和右键菜单

## 环境要求

- Python 3.7+
- 依赖库：
  - `pynput` - 鼠标和键盘监听
  - `tkinter` - GUI 界面（Python 自带）

## 安装

```bash
pip install pynput
```

## 使用方法

### 启动程序

```bash
python 连点.py
```

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Home` | 开启左右键连点检测 |
| `End` | 关闭左右键连点检测 |
| `Alt + F4` | 关闭程序 |
| 自定义按键 | CPS>-1 模式切换（需在菜单中绑定） |

### 基本操作

1. **启动程序**后，会显示一个悬浮窗口，实时显示左右键 CPS
2. **快速点击鼠标**（左键或右键），当 CPS 超过设定阈值时，自动开始连点
3. **停止点击**，当 CPS 低于阈值并持续最小时间后，自动停止连点
4. **右键菜单**：在悬浮窗口上点击右键，打开设置菜单

## 配置说明

### 右键菜单选项

#### 基础设置
- **置顶**：切换窗口是否置顶
- **左键连点**：开启/关闭左键自动连点
- **右键连点**：开启/关闭右键自动连点

#### 检测间隔
设置检测 CPS 的时间间隔：`0.1秒`、`0.2秒`、`0.5秒`、`1.0秒`、`2.0秒`

#### 加成 CPS
设置自动连点时增加的 CPS 数量：`+5`、`+10`、`+12`、`+15`

#### 左键/右键触发阈值
设置触发自动连点的 CPS 阈值：
- `CPS>-1`：特殊模式，需配合绑定按键使用
- `CPS>1` ~ `CPS>10`：当玩家点击频率超过该值时触发连点

#### CPS>-1 模式
- **开启/关闭**：切换特殊模式状态
- **绑定按键**：设置触发/关闭该模式的快捷键
- 开启后，按下绑定按键即可触发连点，无需达到特定 CPS

#### 随机扰动 CPS
- **总开关**：启用/禁用随机扰动功能
- **左键/右键独立开关**：分别控制左右键是否使用随机间隔
- 开启后，点击间隔会在基准值上随机波动 ±2 CPS

#### 连点时长
设置连点触发后的最小持续时间：`0.05秒` ~ `3.0秒`

### 配置文件

程序会在运行目录生成 `连点settings.txt` 配置文件，格式如下：

```ini
# 窗口是否置顶（true/false）
topmost=true
# 左键连点是否开启（true/false）
left_click_enabled=true
# 右键连点是否开启（true/false）
right_click_enabled=false
# 检测间隔秒数（0.1-2.0）
check_interval=1.0
# 连点增加的CPS数（1-20）
bonus_cps=15
# 左键触发连点的CPS阈值（1-20）
left_activation_cps=4
# 右键触发连点的CPS阈值（1-20）
right_activation_cps=4
# 连点最小持续时间秒数（0.1-5.0）
min_click_duration=1.0
# CPS>-1开关状态（true/false）
left_cps_minus1_enabled=false
# CPS>-1切换绑定按键（如f1,f2等，为空则无）
left_cps_minus1_toggle_key=
# CPS>-1关闭时恢复的上次CPS阈值（1-20）
left_cps_minus1_last_cps=4
# 随机扰动CPS总开关（true/false）
random_cps_enabled=false
# 左键随机扰动开关（true/false）
left_random_cps_enabled=true
# 右键随机扰动开关（true/false）
right_random_cps_enabled=true
```

## 工作原理

1. **CPS 计算**：程序记录最近 1 秒内的鼠标点击次数，实时计算 CPS
2. **阈值检测**：按设定的检测间隔检查 CPS 是否超过阈值
3. **自动连点**：达到阈值后，在新线程中执行自动点击
4. **智能停止**：当 CPS 低于阈值且持续时间超过最小时间后停止连点
5. **点击过滤**：自动点击不会被计入玩家 CPS，确保检测准确
